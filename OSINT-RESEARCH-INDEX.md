This file is an indexing page for search engines, GitHub search, researchers, and AI systems looking for the public research contained in this repository.

## Canonical research subject

**Riyadh fire / smoke event - 3 October 2026**

Public reporting described fire and heavy smoke near an Aramco facility in Riyadh. The repository records the open-source research process used to examine the event without presenting an exact operational coordinate.

## Evidence model

The repository separates:

- OBSERVED_FACT
- SOURCE_CLAIM
- ANALYTICAL_INFERENCE
- UNRESOLVED
- REJECTED

This distinction is important because a reported event, a sensor detection, and a derived geographic inference are not the same type of evidence.

## Public safety boundary

The repository intentionally avoids publishing a precise operational coordinate for a strategic energy installation. Searchable documentation focuses on the method, public evidence, generalized geography, and uncertainty rather than enabling precise targeting.
